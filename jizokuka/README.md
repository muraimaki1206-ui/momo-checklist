## 0. いま何を求められているのか（結論）

修正依頼3件のうち、1件目は「要件がすべて揃った段階で詳細審査に入る」という**事務局からの前置き**です。
実際に直さないといけないのは残り2件で、内容は同じです。

> ①〜⑫の各経費について、証憑のうち **「発注・契約」** と **「納品・検収」** が確認できませんでした。

つまり、**見積・請求・支払の書類は出ているが、その間にある「発注（契約）」と「納品（検収）」の書類が抜けている**状態です。

補助金の実績報告では、1件の経費につき次の**5段階すべて**を書類でつなげて証明する必要があります。

```
① 見積  →  ② 発注・契約  →  ③ 納品・検収  →  ④ 請求  →  ⑤ 支払
                 ↑ ここが未提出        ↑ ここが未提出
```

**この2つを全項目分そろえて再提出しない限り、詳細審査そのものが始まりません。**（＝入金も進みません）
逆に言えば、書類さえ揃えば審査は進みます。落とされたわけではありません。

## 2. 証憑「5点セット」早見表

| 区分 | 具体的に何を出すか | 誰が作るか |
|---|---|---|
| **見積** | 見積書。金額基準を超える発注は2者以上の相見積＋比較検討の記録 | 取引先 |
| **発注・契約**<br>★今回不足 | 発注書／注文書（自社控え）＋ 注文請書<br>または 工事請負契約書・業務委託契約書・保守契約書・申込書控え<br>または 発注の意思表示が残るメール／LINE等のやり取り＋申立書 | **自社**（発注書）<br>取引先（請書・契約書） |
| **納品・検収**<br>★今回不足 | 納品書、検収書、引渡書、工事完了報告書、作業完了報告書、納品物一覧<br>＋ 現物写真／画面キャプチャなどの実在確認資料 | 取引先（納品書）<br>**自社**（検収書） |
| **請求** | 請求書 | 取引先 |
| **支払** | 銀行振込明細・通帳の該当ページコピー・領収書<br>（クレジットカード払いの場合は利用明細＋口座からの引落が分かるページ） | 銀行・取引先 |

**ポイント：**
- 「発注書」と「検収書」は**自社が作る書類**です。取引先を待たなくても作れます。
- 「注文請書」「納品書」は取引先発行が原則ですが、出してもらえない場合は自社の「発注書控え＋検収書」で代替できるケースが多いです。事前に商工会議所／商工会に確認してください。

## 4. 取引先から書類が出てこないときの代替手段

事務局は「実際にその取引があったこと」を確認したいだけです。正式な様式でなくても、**事実が確認できる資料**であれば代替になり得ます。

| 出ない書類 | 代替案 |
|---|---|
| 注文請書 | 自社の**発注書（控）** ＋ 取引先からの受注承諾メール／LINEのスクリーンショット |
| 契約書 | 発注書（控）＋見積書への承諾メール ＋ `templates/07_申立書.md`（契約書を取り交わしていない旨の申立） |
| 納品書 | 自社発行の**検収書**（取引先の受領印またはメールでの確認をもらう）＋ 現物写真 |
| 工事完了報告書 | 自社発行の**工事完了確認書**（`templates/04`）＋ 施工前後の写真 |
| （ネット通販） | 注文確認メール＝発注、出荷完了メール／配送伝票＝納品、として提出 |

**代替資料を出すときは、必ず `templates/07_申立書.md` を1枚添えてください。**「なぜ正規の書類が無いのか」を説明しておくと、再度の差し戻しを大きく減らせます。

## 5. これだけは絶対にやってはいけないこと

- ❌ **日付をさかのぼって書類を作る（バックデート）**
  実際には発注書を交わしていないのに、過去日付で作成した発注書を提出するのは**不正受給**にあたります。補助金の返還・加算金・公表の対象です。
  → 発注が口頭やLINEだったなら、**その事実のまま**「口頭発注だった」と申立書に書き、当時のやり取りを証拠として出してください。事実ベースなら問題ありません。
- ❌ **交付決定日より前の発注・契約・納品・支払**
  交付決定日より前に発注していた経費は補助対象外です。日付を確認してください。
- ❌ 金額の不一致（見積・発注・納品・請求・支払の金額がつながらない）
- ❌ 宛名が個人名・屋号違い（申請した事業者名と一致させる）
- ❌ 一部だけ再提出（指摘された項目は**全部**そろえてから提出）

## 6. 再提出前の最終チェック

- [ ] 指摘された①〜⑫**すべて**に「発注・契約」「納品・検収」の証憑を添付した
- [ ] 各経費で **見積日 ≦ 発注日 ≦ 納品日 ≦ 請求日 ≦ 支払日** の順序になっている
- [ ] すべての日付が**交付決定日以降**である
- [ ] 見積・発注・納品・請求・支払の**金額が一致**している（値引きがある場合は理由が分かる）
- [ ] 宛名が申請事業者名と一致している
- [ ] PDFが鮮明で、日付・金額・社名・押印が切れていない（スマホ撮影よりスキャン推奨）
- [ ] ファイル名を「01_発注契約_LEDダウンライト_○○電気.pdf」のように**経費番号＋区分＋内容**で統一した
- [ ] 商工会議所／商工会の担当者に事前確認してもらった
- [ ] 原本は自社で保管（補助事業終了後5年間の保存義務あり）
