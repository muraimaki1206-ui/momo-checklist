## 0. 指摘は2種類あります

修正依頼は3件ありますが、1件目は事務局からの前置き（「要件がすべて確認できた段階で詳細な審査を実施します」）です。
実際に対応すべき指摘は**2つ、しかも中身がまったく違います**。

| | 対象 | 指摘 | やること |
|---|---|---|---|
| **トラックA** | **①〜⑦**<br>機械装置等費 7項目 | 取得物に**「第17回持続化」等の表示**があることを確認できませんでした。表示状況が分かる写真をご提出ください。 | **ラベルを貼って写真を撮る**<br>（書類ではありません） |
| **トラックB** | **⑧〜⑫**<br>広報費・ウェブ・委託外注 | 証憑**「発注・契約」「納品・検収」**が確認できませんでした。必要な証拠書類をご提出ください。 | **書類を集める**<br>（取引先への依頼が必要） |

**この2つは完全に別作業です。同時並行で進めてください。**
トラックAは自分だけで完結するので今日中に着手でき、トラックBは取引先の対応待ちが発生するので依頼だけ先に投げます。

> 審査は要件がすべてそろった段階で始まります。つまり**両方そろうまで詳細審査は始まらず、入金も進みません。**
> 逆に言えば、落とされたわけではありません。そろえれば進みます。

# トラックA｜①〜⑦「第17回持続化」の表示写真

## A-1. 何を求められているのか

補助金で購入した物には、**「第17回持続化」と分かる表示（シール等）を貼る義務**があります。
事務局は、提出された写真にその表示が写っていないため差し戻しています。**書類の不足ではありません。**

やることは3つだけです。

1. ①〜⑦の現物にラベルを貼る
2. 表示が読める写真を撮る
3. アップロードして再提出する

## A-2. 進め方

| ステップ | やること | 目安 |
|---|---|---|
| **A-1** | `templates/08_表示ラベル印刷シート.html` をブラウザで開き、事業者名・取得年月日を入れて印刷する | 30分 |
| **A-2** | ①〜⑦の**すべての現物**に貼る（2台買ったものは2台とも） | 1時間 |
| **A-3** | 1品目につき「全体写真」＋「表示のアップ」の2枚を撮る | 1時間 |
| **A-4** | 経費番号ごとにPDFにまとめてアップロードする | 30分 |

詳しい貼付位置・撮り方・チェック表は `templates/09_撮影チェックリスト.md` にあります。

## A-3. ここで落ちやすいポイント

- ❌ **未開封・未使用の写真はNG。** 段ボール入り・包装されたままの写真では「事業が完了した」と認められません。**設置・使用している状態**で撮ってください。
- ❌ **一部の品にしか貼っていない。** 「購入した商品すべて」が対象です。会議用テーブル2台なら2枚、面談用イス2脚なら2枚です。
- ❌ 表示がぼやけて読めない／光が反射して白飛びしている。
- ⚠️ **①LEDダウンライト**は天井埋め込みで貼りにくい場合があります。器具のすぐ脇や分電盤・スイッチプレート脇にまとめて貼る方法がありますが、**この扱いは事前に事務局または商工会議所／商工会に確認してください。**
- 家具は**天板の裏・座面の裏**など普段見えない面で構いません。写真で読めれば問題ありません。
- ⑥に含まれる**配送料は「物」ではない**のでラベルは不要です。

# トラックB｜⑧〜⑫「発注・契約」「納品・検収」の書類

## B-1. 何を求められているのか

補助金の実績報告では、1件の経費につき次の**5段階すべて**を書類でつなげて証明する必要があります。

```
① 見積  →  ② 発注・契約  →  ③ 納品・検収  →  ④ 請求  →  ⑤ 支払
                 ↑ 未提出            ↑ 未提出
```

見積・請求・支払は提出済みですが、**間の2つが抜けている**状態です。

## B-2. 進め方

| ステップ | やること | 目安 | 担当 |
|---|---|---|---|
| **B-1** | ⑧〜⑫の取引先・金額・日付・手持ち書類を `01_証憑チェックリスト.md` に埋める | 当日 | 自社 |
| **B-2** | **取引先へ不足書類の発行を依頼する**（文例：`templates/06_取引先への依頼文例.md`） | 1〜2日 | 自社→取引先 |
| **B-3** | 取引先から出ない書類は自社作成で代替（発注書控え・検収書・完了確認書） | 2〜3日 | 自社 |
| **B-4** | 商工会議所／商工会の担当者に事前チェックしてもらう | 1〜2日 | 自社＋商工会 |
| **B-5** | 証憑区分「発注・契約」「納品・検収」でアップロード | 半日 | 自社 |

> **最優先はB-2です。** 取引先の対応待ちが一番時間を食います。**今日中に全取引先へ依頼を投げてください。**

## B-3. 証憑「5点セット」早見表

| 区分 | 具体的に何を出すか | 誰が作るか |
|---|---|---|
| 見積 | 見積書。金額基準を超える発注は2者以上の相見積＋比較検討の記録 | 取引先 |
| **発注・契約**<br>★今回不足 | 発注書／注文書（自社控え）＋ 注文請書<br>または 工事請負契約書・業務委託契約書・申込書控え<br>または 発注の意思表示が残るメール／LINE＋申立書 | **自社**（発注書）<br>取引先（請書・契約書） |
| **納品・検収**<br>★今回不足 | 納品書、検収書、引渡書、工事完了報告書、納品物一覧<br>＋ 現物写真／画面キャプチャなどの実在確認資料 | 取引先（納品書）<br>**自社**（検収書） |
| 請求 | 請求書 | 取引先 |
| 支払 | 銀行振込明細・通帳コピー・領収書（カード払いは利用明細＋口座引落が分かるページ） | 銀行・取引先 |

「発注書」と「検収書」は**自社が作る書類**です。取引先を待たなくても作れます。

## B-4. 項目ごとに集めるもの

### ⑧ 広報費：看板制作・設置工事
- 発注・契約：**工事請負契約書 or 発注書（控）＋注文請書**（制作＋設置工事なので契約書が望ましい）
- 納品・検収：**工事完了報告書／引渡書＋検収書** ＋ **施工前・施工中・施工後の写真**、看板デザイン校了データ

### ⑨ 広報費：ロゴデザイン制作
- 発注・契約：業務委託契約書 or 発注書（控）＋制作依頼メール（仕様・納期・金額が分かるもの）
- 納品・検収：**納品データ一覧（ai/pdf/pngなど）＋検収書** ＋ 完成ロゴの画像、実際の使用実績（看板・チラシ・HP等）

### ⑩ ウェブサイト関連費：ウェブサイト制作・写真撮影
- 発注・契約：業務委託契約書 or 発注書（控）＋見積承認メール（ページ構成・撮影内容・金額が分かるもの）
- 納品・検収：**納品確認書（検収書）＋納品物一覧** ＋ **公開URL・全ページの画面キャプチャ**、撮影データの納品一覧（点数・納品方法）

### ⑪ 委託・外注費：内装・外装工事（トイレ改修・ウッドデッキ 等）
- 発注・契約：**工事請負契約書（必須級）**。無い場合は発注書（控）＋注文請書＋工事内訳書
- 納品・検収：**工事完了報告書＋引渡書＋検収書** ＋ **施工前・施工中・施工後の写真**（箇所ごとに）

### ⑫ ウェブサイト関連費：LINE自動集客システム構築
- 発注・契約：業務委託契約書 or 発注書（控）＋要件・仕様が分かるやり取り
- 納品・検収：**構築完了報告書＋検収書** ＋ **管理画面のキャプチャ、実際に稼働している画面（友だち追加〜自動応答）のキャプチャ**、設定内容一覧

## B-5. 取引先から書類が出てこないときの代替手段

事務局は「実際にその取引があったこと」を確認したいだけです。正式な様式でなくても、**事実が確認できる資料**であれば代替になり得ます。

| 出ない書類 | 代替案 |
|---|---|
| 注文請書 | 自社の**発注書（控）** ＋ 取引先からの受注承諾メール／LINEのスクリーンショット |
| 契約書 | 発注書（控）＋見積書への承諾メール ＋ `templates/07_申立書.md` |
| 納品書 | 自社発行の**検収書**（取引先の受領印またはメールでの確認をもらう）＋ 現物写真 |
| 工事完了報告書 | 自社発行の**工事完了確認書**（`templates/04`）＋ 施工前後の写真 |
| （ネット通販） | 注文確認メール＝発注、出荷完了メール／配送伝票＝納品、として提出 |

**代替資料を出すときは、必ず `templates/07_申立書.md` を1枚添えてください。**

## 2. 両トラック共通｜絶対にやってはいけないこと

- ❌ **日付をさかのぼって書類を作る（バックデート）**
  実際には発注書を交わしていないのに、過去日付で作成した発注書を提出するのは**不正受給**にあたります。補助金の返還・加算金・公表の対象です。
  → 発注が口頭やLINEだったなら、**その事実のまま**「口頭発注だった」と申立書に書き、当時のやり取りを証拠として出してください。事実ベースなら問題ありません。
- ❌ **交付決定日より前の発注・契約・納品・支払**（補助対象外になります）
- ❌ 金額の不一致（見積・発注・納品・請求・支払の金額がつながらない）
- ❌ 宛名が個人名・屋号違い（申請した事業者名と一致させる）
- ❌ **一部だけ再提出**（A・B両方そろえてから提出）

- [ ] 拡大して「第17回持続化」の文字がはっきり読める
- [ ] 経費番号ごとにPDFにまとめた

**トラックB（⑧〜⑫）**
- [ ] ⑧〜⑫すべてに「発注・契約」「納品・検収」の証憑を添付した
- [ ] 各経費で **見積日 ≦ 発注日 ≦ 納品日 ≦ 請求日 ≦ 支払日** の順序になっている
- [ ] すべての日付が**交付決定日以降**である
- [ ] 金額がすべて一致している
- [ ] 宛名が申請事業者名と一致している

**共通**
- [ ] PDFが鮮明で、日付・金額・社名・押印が切れていない
- [ ] ファイル名を「経費番号＋区分＋内容」で統一した
- [ ] 商工会議所／商工会の担当者に事前確認してもらった
- [ ] 原本は自社で保管（補助事業終了後5年間の保存義務あり）
