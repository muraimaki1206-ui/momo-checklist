## 使い方
1. まず「取引先」「金額」「日付」を埋める（システムの経費内訳一覧を見ながら）
2. 手持ちの書類に ✅、無いものに ❌ を付ける
3. ❌ の行だけを取引先に依頼／自社で作成する
4. アップロードしたら「済」に ✅

凡例：**発注** = 発注・契約　／　**納品** = 納品・検収

## D. アップロード時のファイル名ルール（推奨）

```
[経費番号]_[証憑区分]_[内容]_[取引先].pdf

例）
01_発注契約_LEDダウンライト_○○電気.pdf
01_納品検収_LEDダウンライト_○○電気.pdf
11_発注契約_内装外装工事_△△工務店.pdf
11_納品検収_内装外装工事_△△工務店.pdf
```

複数枚は1つのPDFに結合してからアップロードすると、事務局側で確認漏れが起きにくくなります。

## E. 提出前の最終確認

- [ ] ①〜⑫すべてに「発注・契約」「納品・検収」を添付した
- [ ] 見積日 ≦ 発注日 ≦ 納品日 ≦ 請求日 ≦ 支払日 の順になっている
- [ ] すべての日付が交付決定日以降
- [ ] 全書類の金額が一致している
- [ ] 宛名が申請事業者名と一致
- [ ] スキャンが鮮明（日付・金額・社名・押印が読める）
- [ ] 商工会議所／商工会の事前チェック済み
- [ ] 原本を保管した（5年間）
