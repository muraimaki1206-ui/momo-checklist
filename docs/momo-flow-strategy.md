## 3. 第2回 ウーマンズヘルスフェスタ 計画

### 3-1. 基本設計
- **会場**：前回と同じ千葉の300人ホール（スタッフ導線・音響・搬入を前回の経験で回せる）
- **日程**：要確定（v1では2027年9月目標）
- **ホールの予約は6ヶ月前から**。9月開催なら3月に予約 → **第1〜第3希望日を決めておく**／取れなかった場合の代わりの日も用意
- **時間**：前回同様 約2時間
- **やめること**：エントランスの催し物
- **集中すること**：本編（ダンス／体のライフステージ／トーク／抽選会／全員で This is Me）

### 3-2. プログラム案（前回をベースに）
| 順 | 内容 | 前回からの変更点 |
|---|---|---|
| 1 | オープニングダンス | 練習してきた参加者・会員が踊る |
| 2 | 女性の体のライフステージ | 前回の内容をブラッシュアップ |
| 3 | トークセッション「幸せ」 | **モモジム会員のリベシティメンバーが登壇** |
| 4 | 新しい試み（1枠） | 候補は下記 |
| 5 | 抽選会 | 協賛品を集める（登壇者・会員のつながりで） |
| 6 | 全員で This is Me | 事前に練習動画を公開しておき、会場全体で踊る |

**「新しい試み」の候補**
- 練習を重ねてきた人たちの「ビフォー／アフター」紹介（数ヶ月の練習記録を1〜2分の映像に）
- 来場者の「This is Me」を事前募集してスクリーンに流す
- 登壇者の小さなブース（**エントランスではなく本編後の短い交流時間**に限定し、負担を増やさない）

### 3-3. フェスタの位置づけ（2026年11月 決定）
- **目的は「300人を必ず埋める」こと。黒字化は一番の目的にしない**
- ただし**ジリ貧にならない**ように収支は設計する
- フェスタの費用の一部は **YouTube・モモジムの広告宣伝費** と捉える

### 3-4. チケット設計（決定事項＋案）
| 区分 | 価格 | 枚数 | 内容 |
|---|---|---|---|
| **ダンス出演チケット** | **3,000円程度**（Tシャツ込みなら4,000円も検討） | 練習会の定員まで | 練習会参加＋本番ステージ出演＋**おそろいTシャツ**。**練習参加者こそきちんと有料に** |
| **特典付き先行チケット** | 要検討（例：3,000〜5,000円） | **限定数**（例：50〜100枚） | 下記の特典から2〜3個 |
| **一般チケット** | **1,000円程度** | 残り全部 | 入場のみ |

- ❌ **オンラインレッスン1年無料はやらない**（継続コストになるため）
- チケットの種類は増やしすぎない（迷うと買わない）

**おそろいTシャツ**
- 出演者全員でそろえる → 一体感／Instagram映え／当日ステージの見栄え
- 原価の目安：オリジナルプリント小ロットで1枚 1,000〜1,500円前後（枚数・色数で変わるので見積もりを取る）
- **背中に協賛社ロゴ** → 協賛のリターンになり、Tシャツ代を協賛でまかなえる可能性
- 一般来場者・特典付きチケットにも販売 or 特典にする → 会場全体で This is Me を踊るときの一体感
- 練習会の回数・期間を決めてから、価格に「Tシャツ込み／別」を確定

**特典アイデア（継続コストがかからないもの中心）**
| 種類 | アイデア |
|---|---|
| 物語系 | 真紀からの**手書きの「MOMOの手紙」**／パンフ・エンドロールに**サポーターとして名前掲載** |
| 体験系 | 前方の優先席／**リハーサル見学**／終演後の登壇者との少人数お茶会／ステージで記念撮影 |
| モノ系 | MOMOシンボル（懐中時計モチーフ）の**限定グッズ**（チャーム・トート・手ぬぐい等） |
| ジム系 | 期限つきモモジム体験・利用券（地域の人向け、入会のきっかけ） |
| 参加系 | This is Me 振付の**限定解説動画**（当日一緒に踊れるように） |

### 3-5. 協賛（リターンを返せる環境を整える）
「ただもらう」ではなく、**協賛企業・個人にちゃんと返せるメニュー**を用意する。

| 口数の例 | リターン案 |
|---|---|
| 個人応援（例：1口 3,000円） | パンフ・エンドロールに名前／お礼の手紙 |
| 小口協賛（例：1〜3万円） | パンフにロゴ／Instagram・YouTubeで紹介投稿 |
| 大口協賛（例：5万円〜） | 上記＋**出演者Tシャツの背中にロゴ**＋抽選会で商品紹介の時間／終演後の交流時間にブース／サンプリング配布 |
| 全協賛共通 | **来場者アンケートで、40〜50代女性の声をレポートとして返す**（企業にとって価値が大きい） |

- 抽選会の景品提供は、協賛の入口として頼みやすい
- 協賛資料（1枚もの）を作る：前回の写真・来場者数・客層・YouTube／Instagramの数字

### 3-6. 300人の集め方（積み上げ）
| 層 | 目安 | 届け方 |
|---|---|---|
| ダンス出演者 | 例：30〜50人 | 練習会 |
| 出演者・登壇者の家族・友人 | 例：80〜120人 | 出演者が自分で誘う（**招待の言葉・画像を用意する**） |
| モモジム会員 | 例：30〜50人 | ジム内の告知・声かけ |
| 前回来場者 | 例：50人〜 | LINE・前回の名簿から先行案内 |
| リベシティ・SNS・YouTube | 残り | Instagramでプロセス発信、リベシティ |
| 協賛企業のつながり | 若干 | 協賛社からの告知 |

- **月ごとに販売数を記録**し、足りない層に手を打つ

### 3-7. 人を巻き込む仕組み
- **登壇者**：モモジムに入会しているリベシティの方々 → 本人の発信で告知が広がる
- **ダンス練習**：有料の練習会（ジム内＋オンライン）。練習参加者は「お客さん」ではなく**一緒につくる仲間**
- **手伝ってくれる人**：前回頼れた人に、早めに役割を相談（受付・音響・撮影・抽選会）

## 4. 発信方針（変更）

| 媒体 | 役割 |
|---|---|
| **YouTube** | **運動コンテンツ**（更年期世代向けエクササイズ・ダンス・ストレッチ）。トーク系は一旦停止 |
| **Instagram** | **フェスタまでのプロセス配信**（練習会の様子・準備の裏側・出演者の変化）。リール＋ストーリーズ |
| LINE | 先行チケット・練習会の案内 |

- プロセスは**配信し続ける**。物語はInstagramで、運動はYouTubeで
- Instagram ストーリーズ：練習会の日常を気軽に／リール：週1〜2本、変化や感動の瞬間を切り抜き
- 停止したトーク企画（MOMOの手紙・インタビュー）はストックとして保存（付録）。手書きの「MOMOの手紙」は特典として活用

## 5. 導線・SNS運用

- 公式LINE：「MOMO FLOW」に改名して入口化。**フェスタの先行案内はLINE登録者から**
- 新規登録者には**すぐ個別に一言メッセージ**
- X：本文にリンクを入れず、自分へのリプライでURL
- Instagram：リール（運動・ダンス練習の切り抜き）＋プロフィールにリンク
- Facebook：インスタ連携で同時投稿
- リベシティ：健康情報の発信で信頼 → 会員の登壇・フェスタ告知

## 付録：一旦停止したトーク企画のストック

### MOMOの手紙（型）
- 冒頭：「今日は〇〇なあなたに、手紙を書きました。」／締め：「真紀より。」

### テーマ（20本）
- 自分を責めてきた：性格悪いからと思ってきた／完璧な母親になれなかった／期待に応え続けて疲れた
- 転換期：40代で仕事を変えるか迷う／子育てが終わって空っぽ／離婚して一人になった
- 体の変化：更年期で自分が変わった／眠れない夜／体が思うように動かない
- 生き方：結婚しなかった自分を責めている／誰かのために生きてきた／50代でも夢を持っていい？
- 取り戻す：幸せってなんだろう／居場所がない／やっと自分になれた気がする

### インタビュー質問（13問）→ フェスタのトークセッションにも転用可
- 導入：今どんな毎日？／自分を一言で言うと？
- 過去：一番しんどかった時期／期待に応えて無理したこと／「これでいいのかな」と思った瞬間
- 転換点：変わったきっかけ／自分を許せた瞬間／今の自分を昔の自分に見せたら？
- 今：自分のことが好き？／あなたにとって幸せとは？／これが私だと思えるものは？
- 未来：これからどんな自分でいたい？／同じ悩みの女性に一言
